# ポスター編集ツール

デモポスターの紙面（`poster/poster.json`）を、ブラウザ上で見ながら直すためのツールです。

```sh
python3 tools/poster-editor/serve.py
# → http://localhost:8010/tools/poster-editor/
```

## できること

- **表示の拡大・移動**
  - 2 本指のスワイプかマウスのホイールで紙面を動かし、ピンチか ⌘＋ホイールでカーソルの位置を中心に拡大・縮小します（5〜800%）。
  - スペースを押しながらのドラッグや、中ボタンのドラッグでも動かせます。
  - ⌘+ ⌘− で段階的に拡大・縮小、⌘0 で全体、⌘1 で 100%。上の「表示」でも選べます。「全体」はウィンドウの大きさに合わせ直します。
- **選択と移動**
  - 紙面をクリックすると、その要素を選択します。重なっているときは、いちばん小さい要素が選ばれます。
  - ⇧ を押しながらクリックすると、選択に足したり外したりできます（左の要素の一覧でも同じ）。選んだものはまとめてドラッグ・矢印キーで動き、Delete でまとめて消え、⌘D でまとめて複製されます。右の欄の項目は、最後にクリックした 1 つだけに効きます。
  - ドラッグで移動します。⇧ を押しながらだと u（12px）単位、⌥ を押しながらだと連動する要素を置いて単独で動きます。
  - 矢印キーで 1px ずつ（⇧ で 10px）動かせます。
- **スナップとガイド**：ドラッグ中、選んだものの端（左・右・上・下）か中央が、ほかの要素や紙面の端・中央にそろう位置（画面で 6px 以内）に吸い付き、そろったところにピンクの線が出ます。⌘ を押している間と、上の「スナップ」を外しているときは吸い付きません。がらくたの範囲・点の散らばり・枠には吸い付きません。
- **整列**：左の欄の 6 つのボタンで、左端・左右の中央・右端・上端・上下の中央・下端をそろえます。2 つ以上選んでいると、それらを囲む枠にそろえ、1 つだけなら紙面にそろえます。連動する要素は一緒に動きます。
- **連動**：各要素の「連動する図形」に図形の名前を入れると、その図形を動かしたときに一緒に動きます。注記や fig.7 の中心の赤丸がこれを使っています。
  - 回転：図形の「回転°」を変えると、連動する要素もその図形の中心のまわりに同じだけ回ります（fig.5 の道路と白線、fig.1 の脚など）。文字と注記は、位置だけが回って字は水平のままです。
- **項目の編集**：右の欄で位置・大きさ・色・模様の間隔・角度・文字などを変えると、その場で紙面に反映されます。
- **文字の字間**：値はどちらも 1/1000 em（Illustrator と同じ）なので、文字の大きさを変えても比率は保たれます。
  - 字間（トラッキング）：「文字」の右の欄の「字間」で、その要素の文字の間をすべて同じだけ詰める（マイナス）／空ける（プラス）。
  - ペアカーニング：紙面の文字をダブルクリックすると、文字の間にカーソルが出ます。⌥← ⌥→ でその 1 か所を 10 ずつ（⇧ も押すと 100）詰める／空けます。← → ↑ ↓ でカーソルを動かし、Delete でその間を 0 に戻し、Esc で終わります。カーソルが出ている間は、クリックするとカーソルが動き、文字はドラッグで動きません。
  - 本文を書き換えても、ペアカーニングは同じ 2 文字の間に付いたままです。2 文字の間に文字を入れると、その間の調整は消えます。調整した間の数は右の欄に出て、「ペアカーニングを消す」でまとめて消せます。
- **配色**：配色の 1 色（`ink`、`red` など）を変えると、その色名を使っている要素がすべて変わります。色の欄には、色名のほか `#RRGGBB` や `rgba(…)` も書けます。
- **要素の管理**：追加・複製（⌘D）・削除（Delete）・重なり順（↑↓）・表示と非表示（●／○）を左の欄で操作します。
- **元に戻す**：⌘Z で戻す、⇧⌘Z でやり直す。
- **がらくたを撒く**：がらくた（`debris`）を選ぶと、右の欄の下にボタンが出ます。
  - 「隙間に撒く」：ほかの図形・文字・隠し板から「ほかとの隙間」（既定 24px）以上離れた場所に、範囲（x・y・範囲の幅・範囲の高さ）の中で「個数」ぶん撒きます。押すたびに乱数の種が 1 つ進み、別の撒き方になります。三角と棒は向きもばらばらになります（1 個ずつ「回転°」で変えられます）。隙間が足りないときは小さくして置き、それでも入らない分は置きません（上の欄に出ます）。
  - 「今の配置をばらす」：種から描いている今の見た目のまま、1 個ずつの要素にします。
  - 撒いたりばらしたりしたがらくたは 1 個ずつの要素（`piece`）になり、選んで動かす・消す・形や色を変えることができます。がらくたの要素に連動しているので、範囲ごとドラッグすると全部が一緒に動きます。
  - 手で動かしたり項目を変えたりしたものは「固定」になり、撒き直しても残ります（「固定したものは残す」を外すと全部撒き直します）。
  - 淡い色（不透明度が半分未満）の上には置けます。置きたくない場所には、地の色の四角を置くと避けます。
- **カメラで見る**
  - カーソルの位置をスマホの画面として、アプリと同じ検出器で検出し、見つかった模様を枠で示します。
  - クリックで位置を固定し、「画角」で引き寄せと引きを変えます。
  - 判定は 1 フレームぶんです。アプリでは、数フレーム続けて検出されると鳴ります。
- **保存**：⌘S または「保存」で `poster/poster.json` を上書きします。1 つ前の版は `poster/poster.json.bak` に残ります（git 管理外）。
- **書き出し**：PNG（印刷確認用、2 倍）、JSON の書き出しと読み込み。
- **確認**：「アプリで確認」を押すと、保存した紙面でアプリのデモが開きます。

## 要素の種類

| 種類 | 用途 |
| --- | --- |
| 模様の図形 `pattern` | 円・四角・多角形・輪の中に、縞・格子・点（六方・正方形）・同心円・放射を描く。点の模様は六方（`hexdots`）と正方形（`dots`）。「枚数」を 2 以上にすると、図形をその枚数（1 辺）に分け、1 枚ずつに切れない点を並べる（点字ブロック、fig.8 は正方形で 1 枚に 5×5。「目地の幅」は枚の間） |
| 図形の繰り返し `repeat` | 模様の図形を縦横に並べる（fig.6）。「全体の回転°」で並びごと、「1 個ずつの回転°」で 1 個ずつの模様が回る |
| 似たものの並び `row` | 瓶・本・ブロック・カップを、指定した間隔（u）で並べる |
| 四角・円と扇形・弧・線・市松 | 身近なものの細部や台、がらくた |
| 文字・注記 | 本文と、引き出し線つきの注記 |
| がらくた `debris`・点の散らばり | 種（seed）から作る、繰り返さない飾り。がらくたは隙間に撒き直せる（上の「がらくたを撒く」） |
| がらくた（1 個） `piece` | 三角・円・棒の 1 個。撒いたりばらしたりすると作られる |
| 2 次元コード `qr` | アプリの URL などを QR コードにして載せる。1 マスの大きさは整数 px（印刷で境目がにじまない）。余白は付けない（枠がコードの外周に合う）ので、読み取りのため、まわり 4 マスほどは何も置かない |

横断歩道なら「模様の図形（四角＋縞、線の向き 90°）」、本棚なら「似たものの並び（本）」と「四角」（棚板）を組み合わせると作れます。

## アプリとの関係

- このフォルダ（`tools/poster-editor/`）は、アプリの描画（`src/poster/poster.js`）と検出器（`src/detect/detector.js`）を**読むだけ**です。アプリ側はこのツールを参照していないので、フォルダごと消してもアプリは動きます。
- 要素の種類を増やしたり描き方を変えたりするときは `src/poster/poster.js` を直します。このツールの項目欄は、そこに書かれた項目の定義から自動で作られます。
